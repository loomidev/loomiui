This release makes LoomiUI lighter to download. Until now, every component with built-in text shipped all ten included languages, whether your app used them or not. Now only English ships up front and other languages download the first time you switch to them. A text input, for example, drops from about 26 KB to about 17 KB (minified and gzipped, excluding `lit`). Switching languages now waits for the download, so read **Breaking changes** if your code switches language and then expects the new text straight away.

## Languages download when you need them

Set a language as before. LoomiUI now downloads it the first time, once, and then switches. Components already on the page update to the new language on their own.

```js
import { setLoomiLocale } from "@loomidev/core";

await setLoomiLocale("fr"); // downloads French, then switches
```

A regional locale such as `fr-CA` also downloads its base language, `fr`. An unknown locale shows English and downloads nothing.

A component with its own `locale` attribute works too. If that language hasn't downloaded yet, the component shows English for a moment and then switches. To show it translated from the start, load the language before the component renders:

```js
import { loadLoomiLocale } from "@loomidev/core";

await loadLoomiLocale("de"); // download German without switching the page to it
```

Your own translations still work the same way. `defineLoomiTranslations()` overrides keep priority over the included text, even if you register them before the language downloads.

## Faster first icon

The first icon a page loads by name (`icon="bell"`) used to fetch a 4.4 KB list of every icon first. That list is now 3.5 KB. Each icon is still its own small file, downloaded the first time it shows.

## Breaking changes

- **`setLoomiLocale()` now waits for the language to download.** It returns a promise and switches once the language has arrived. If your code reads translated text or checks `getLoomiLocale()` right after the call, add `await`: `await setLoomiLocale("es")`. Switching to English, to a language you registered with `defineLoomiTranslations()`, or to an unknown locale still happens immediately.
- **`builtinTranslations` lists downloaders, not translations.** Each entry is a function that downloads that language: use `await builtinTranslations.fr()` to get the French text. `loomiTranslations` now holds only the languages downloaded or registered so far.

## Upgrading

```sh
npm install @loomidev/components@^0.13.0
```

If you install components one by one, change each `@loomidev/*` dependency to `^0.13.0`. Because these are 0.x versions, a `^0.12.0` range won't pick up this release on its own.

Every package's CHANGELOG has the full list of changes.

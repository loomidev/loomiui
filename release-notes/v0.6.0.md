This release adds two new components, a breadcrumb and a skeleton loader, and fixes one of the more annoying layout problems: dropdowns and tooltips no longer make a modal or a scrolling table grow a scrollbar when they open.

## New components

- **Breadcrumb** (`@loomidev/breadcrumb`) shows people where the current page sits in your site. It includes a chevron style with full-height dividers and works in right-to-left layouts.
- **Skeleton** (`@loomidev/skeleton`) is a placeholder you show while content loads. Use it for lines of text, circles such as avatars, or blocks.

## Dropdowns inside modals

Opening a select, a date picker or a tooltip inside a modal used to push the modal's content down and make it scroll, and the close button scrolled away with it. Dropdown panels now sit on top of the page instead of taking up space in it, so the modal stays the same size. When there isn't room below a field, the panel opens above it.

This applies to select, autocomplete, countries, the date, time, timezone and color pickers, tag input suggestions, the password prefix menu, popover, tooltip and the chart export menu. The same fix stops a tooltip in the last column of a table from adding a horizontal scrollbar.

Modals are also tidier. Long content now scrolls inside the modal while the close button and the buttons at the bottom stay where they are, and the space on the left and right is now the same.

## Other changes

- **Progress:** a new semicircle gauge (`<loomi-progress-arc>`), new `circle` and `bar` styles for progress steps, and steps people can click through, with optional checks before they move to the next one. Step circles now stay lined up when a description wraps onto a second line. Setting a boolean attribute to `"false"`, such as `show-percentage-label-inline="false"`, now actually turns it off.
- **Button and button group:** a new `circle` option for round, icon-only buttons.
- **Table:** you can now write a static table straight in HTML by putting your header cells in `<template slot="header">` and your rows in `<template slot="body">`.
- **Icon:** badge corner rounding (`radius`) works again.
- **Theming:** set `--loomi-control-border-width` once to change the border width of every form field.

## Breaking changes

- `<loomi-button>` now only accepts `border-width="1"`, the new default, or `"2"`. The `4` and `8` options are gone and fall back to `1`.
- `outline` only changes primary buttons. Secondary buttons already have an outline, so `type="secondary" outline` looks the same as `type="secondary"`.

## Upgrading

```sh
npm install @loomidev/components@^0.6.0
```

If you install components one by one, change each `@loomidev/*` dependency to `^0.6.0`. Because these are 0.x versions, a `^0.5.0` range won't pick up this release on its own.

Every package's CHANGELOG has the full list of changes.

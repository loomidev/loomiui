This release makes LoomiUI form controls behave like native fields in the places server-rendered forms rely on most, turns the last few "clickable" components into real links, and closes a security hole in the card component. Two changes need a look before you upgrade; they're at the top.

## Before you upgrade

**Fields with several values now submit one entry per value.** `loomi-select multiple`, `loomi-checkcards` (when `max` isn't 1) and `loomi-tags` used to send one comma-joined value (`tags=a,b`). They now send each value separately (`tags=a&tags=b`), exactly like a native `<select multiple>`. If your server split the comma string, read the repeated entries instead. In PHP and Laravel, end the field name with `[]` and you get an array:

```html
<loomi-select name="countries[]" multiple data="..."></loomi-select>
<!-- submits countries[]=gh&countries[]=ng -->
```

Reading `.value` in JavaScript still gives `"gh,ng"`, and `.values` gives the array.

**Card URLs are never run as code.** `loomi-card` and `loomi-contact-card` used to run a `url` ending in `)` as JavaScript. That was a script-injection risk whenever a URL came from user data, so it's gone. If you used it, listen for `click` on the card instead.

## Forms that behave like native forms

- **Disabled fieldsets work.** Put LoomiUI fields inside `<fieldset disabled>` and they're disabled too, and left out of the submission, just like native inputs. Handy for locking a form while it saves.
- **Back button and autofill keep what was typed.** If someone fills a form, navigates away and comes back, LoomiUI fields now get their values back, like native ones do.
- **Server errors on every field.** The `error` attribute from 0.15 now works on every form control, including checkboxes ("You must accept the terms"), radios, toggles, date and time pickers, autocomplete, tag input, OTP and the text editor.

```html
<loomi-checkbox name="terms" label="I accept the terms" error="You must accept the terms"></loomi-checkbox>
```

## Real links

`loomi-card`, `loomi-contact-card` and `loomi-statistic` now render `url` as a real link. They open in a new tab, show their address on hover and work without JavaScript. A new `target` attribute controls where they open (absolute `https://` URLs still open in a new tab by default). The "add new" action in an empty `loomi-select` is a real link too when you give it `empty-action-url`.

Links and buttons placed inside a linked card still work on their own. `loomi-contact-card` also no longer navigates twice per click.

## Upgrading

```sh
npm install @loomidev/components@^0.17.0
```

If you install components one by one, change each `@loomidev/*` dependency to `^0.17.0`. Because these are 0.x versions, a `^0.16.0` range won't pick up this release on its own.

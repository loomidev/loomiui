This release is mostly about accessibility and phones. Automated accessibility checks (axe) found several controls that screen readers couldn't name or keyboard users couldn't reach, and a profile menu that made pages too wide on a phone. All of those are fixed, and a few things that used to need workarounds are now built in.

## Pickers work properly with screen readers

The select, countries, timezone and color pickers now follow the standard pattern for this kind of control (a "select-only combobox"). In practice:

- A screen reader announces the field's label and its current value, for example "Crop, combobox, Maize". Before, a select showing only its placeholder had no name at all.
- While the list is open, the highlighted option is announced as you move through it, including while you type in the search box.
- A picker without a visible label can now be named with `aria-label`, for example `<loomi-select aria-label="Workspace">`.

## Better on phones

- **Profile menu:** add `compact` to show just the avatar and the arrow, or `compact="auto"` to do that only on small screens. Before, the menu was at least 224px wide, which pushed a phone-sized header past the edge of the screen and made the browser zoom the whole page out. The name and email are still read out to screen reader users. To keep the full menu but let it shrink in a tight space, set `--loomi-profile-menu-min-width: 0`; long names then end in "…".
- **Table:** when a table is too wide for the screen, keyboard users can now Tab to it and scroll it sideways with the arrow keys. A focus ring shows where they are.

## Other changes

- **Tabs:** tab icons can now come from the iconsax and untitledui icon sets as well as the default heroicons, with `icon-source` and `icon-variant`. They load on their own; there's nothing to register.
- **Button group:** add `tooltip` to an item to show a tooltip on hover and keyboard focus. You no longer need to wrap each item in `<loomi-tooltip>`.
- **Button group:** icon-only buttons are now always read out by name, for example "View as list, toggle button, pressed". In some setups they had no name.
- **Styling hooks:** the profile menu and table expose more parts for styling from outside (`::part(trigger)`, `::part(name)`, `::part(scroll)` and others), so you don't need to reach into their shadow DOM.

## Breaking changes

- The select, countries, timezone and color picker triggers are now comboboxes, not buttons. Your app works the same, but tests or scripts that find them by role need updating: for example, change Playwright's `getByRole("button", { name: "Crop" })` to `getByRole("combobox", { name: "Crop" })`.

## Upgrading

```sh
npm install @loomidev/components@^0.7.0
```

If you install components one by one, change each `@loomidev/*` dependency to `^0.7.0`. Because these are 0.x versions, a `^0.6.0` range won't pick up this release on its own.

Every package's CHANGELOG has the full list of changes.

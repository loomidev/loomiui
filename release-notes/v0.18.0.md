This release fixes the gaps reported from a production app in issue #208. Theme colours now work in page CSS, and you can set any theme token from `:root`. Buttons behave more like native submit buttons. Hand-written tables are easier to style, and `loomi-empty-state` is about 125 kB smaller. Two changes need a look before you upgrade; they're at the top.

## Before you upgrade

**Theme tokens set on `:root` now apply inside components.** Before, setting `--loomi-surface`, `--loomi-text`, `--loomi-text-on-primary` or the other surface and text tokens on `:root` had no effect inside components. Now it does, just like the palette colours. If you once set one of these on `:root` and it seemed to do nothing, it will start working, so check it still looks right. A token you set is used in light and dark mode; leave it unset to keep the automatic dark-mode switch.

**`color="secondary"` on a solid button is now filled.** It used to give the same grey outline as `type="secondary"`. It now fills with your secondary brand colour, like every other `color`. For the grey outline, use `type="secondary"`.

## Theme colours in your own CSS

`@loomidev/theme/tailwind-colors.css` had an invalid fallback, so utilities such as `border-gray-200` or `text-error-600` on your page came out transparent or in the text colour. That's fixed, and the file now carries the default colours itself, so it works on its own.

There's also a new `@loomidev/theme/defaults.css` with every default value, for page CSS that doesn't use Tailwind.

## Buttons

- **Text on light colours.** Filled buttons used white text, whatever the colour. Set `--loomi-text-on-primary` (or `--loomi-text-on-warning`, `--loomi-text-on-success`, …) to give a light fill dark text:

```css
:root {
  --loomi-text-on-warning: #1c1917;
}
```

- **Several submit buttons in one form.** Give a submit button a `name` and `value`, and the button that was pressed is sent with the form, as with native buttons:

```html
<loomi-button can-submit name="action" value="approve">Approve</loomi-button>
<loomi-button can-submit name="action" value="reject" color="error">Reject</loomi-button>
<!-- pressing Reject sends action=reject -->
```

- **`element.click()` works.** Calling `click()` on a `<loomi-button>`, as scripts and test tools do, now submits its form or follows its link, like a native button.
- A `<fieldset disabled>` now disables buttons inside it.

## Styling hand-written tables

Rows written in a `<template>` live inside the table, out of reach of page CSS. You now have more ways in:

- Ready-made cell content: `badge` (a status pill, with `badge-success`, `badge-error`, `badge-warning` and so on), `muted` (a smaller second line), `thumb` (a square image) and `actions` (right-aligned buttons or links).
- A `part` you write in the template can be styled from the page: `<span part="status">` with `loomi-table::part(status)`.
- A `<template slot="styles">` holding a `<style>` is applied inside the table.

```html
<td>Rice, 5kg<span class="muted">SKU 1042</span></td>
<td><span class="badge badge-success">In stock</span></td>
```

## Smaller additions

- **Required card choices.** `loomi-checkcards` takes `required`: the form won't submit with nothing chosen, and the chosen card can't be clicked off. Use it for delivery addresses, shipping speed or payment methods.
- **Take a photo.** `loomi-filepicker` takes `capture="environment"` (rear camera) or `capture="user"` (front camera), so phones open the camera straight away.
- **Lightbox frames.** The `loomi-lightbox-image` trigger fills its host and has `part="trigger"`, so you can put a photo in a fixed square frame and style its focus ring.
- **A much smaller empty state.** The built-in illustration is now a small WebP that loads only when it's shown, so importing `loomi-empty-state` no longer adds about 170 kB.

## Upgrading

```sh
npm install @loomidev/components@^0.18.0
```

If you install components one by one, change each `@loomidev/*` dependency to `^0.18.0`. Because these are 0.x versions, a `^0.17.0` range won't pick up this release on its own.

# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1, as its code of conduct. Everyone who participates in LoomiUI — contributors,
maintainers, and community members — is expected to uphold it in all project spaces,
including issues, pull requests, and any other channels.

In short: be respectful and constructive, assume good faith, and help keep this a
harassment-free space for everyone regardless of background or experience level.

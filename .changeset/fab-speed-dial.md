Add `<loomi-fab>`, a floating action button that becomes a speed-dial menu when given `<loomi-fab-item>` children — corner `placement`, expand `direction`, `click`/`hover` triggers, `floating`/`docked` variants, an optional `backdrop`, `icons-only` mode (labels shown as a `<loomi-tooltip>` instead of inline text), and roving keyboard navigation. Icons render through the same `<loomi-icon>` registry and `icon-source` attribute as `<loomi-bottom-nav>`.
